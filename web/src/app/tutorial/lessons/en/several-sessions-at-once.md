# Several sessions at once

## Start another
advance_on: continue
primary: New session
action: new-session

Any project can have more than one session, and they can be different agents. Start a second one from the + on the project row. Each is its own terminal with its own conversation.

## Switch between them
advance_on: continue

Select a session in the side panel to bring it forward. The others keep running. Rename a session from its row menu so you can tell them apart; Deck colors each project so sessions from the same project match.

## Close one
advance_on: continue

Closing a session ends its process. Deck asks first unless you turn that off in the global menu.
