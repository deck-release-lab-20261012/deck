# Files and uploads

## Browse
advance_on: continue
opens: files

Files shows the working tree of the selected project. Open folders, read text and images. It's a viewer; edit in your editor or ask the agent.

## Upload
advance_on: continue
primary: Upload files
action: upload-files

Drop files into the open folder or choose Upload files. If a name already exists you choose Replace, Upload as, or Cancel. Files are limited to 32 MiB each.

## When an upload is unsure
advance_on: continue

Progress shows bytes sent; the server confirms afterwards. If you stop waiting during that confirmation the result is reported as unknown, so look in the folder before uploading again. Deck never retries an upload on its own.
