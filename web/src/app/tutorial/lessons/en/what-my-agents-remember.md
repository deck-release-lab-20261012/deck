# What my agents remember

## One memory for all agents
advance_on: continue

MemPalace is a shared memory that every agent on this Deck can search and write to. What one agent learns about a project, a decision or a mistake is there for the next one, in any project and on any harness.

## How agents use it
advance_on: continue

Agents search it before answering questions about past work and save checkpoints at milestones. The a2a chat you saw in lesson 2 runs on the same store. Nothing is mined from your projects automatically.

## Looking at it yourself
advance_on: continue
command: mempalace search "release notes"

Run mempalace search in any terminal to see what's there.
