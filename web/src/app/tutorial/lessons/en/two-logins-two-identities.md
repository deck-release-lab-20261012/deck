# Two logins, two identities

## Deck's login and the agent's login
advance_on: continue

You sign in to Deck once, in the browser. Each agent signs in to its own vendor, in its own terminal, with its own account. Sign out in Deck never signs an agent out.

## Git identity and GitHub
advance_on: continue
primary: Git identity…
action: git-identity

Git identity is the name and email on your commits; set it in the global menu, or per project. Connect GitHub is separate: it's what lets Deck clone and push to your repositories.

## The switches
advance_on: continue

Yolo mode lets new sessions skip permission prompts. The two confirmation settings ask before closing a session or removing a project. Reading this changes none of them.
