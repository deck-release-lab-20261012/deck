# What an agent here can reach

Deck runs coding agents natively on this machine. That means an agent can read and change anything under `/workspace`, including other projects, and it can use any credential the runtime holds, such as your GitHub login. A project folder is not a wall between agents (yet).

Deck itself listens on this computer only. It keeps no transcripts and never sends anything on your behalf. Whatever coding agents natively do, whether they send or don’t send data, we do not change that behavior.

Give an agent only what you would give every agent.
