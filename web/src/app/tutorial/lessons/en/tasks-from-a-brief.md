# Tasks from a brief

## Add a PRD
advance_on: continue
opens: tasks
primary: Add PRD…
action: add-prd

A brief is any Markdown file that says what you want. Add it to a project from the Tasks panel. If the project already has one, Deck asks before replacing it.

## Generate tasks
advance_on: continue
primary: Generate tasks
action: generate-tasks
primary_note: Uses your Claude plan or API key.

Generate tasks reads the brief and adds tasks to the board with titles, details, priorities and dependencies. Try it on the relnotes PRD from lesson 1: you get two tasks, and the second depends on the first. Read what it produced; you can edit or delete any of it.

## Work the board
advance_on: continue

Add tasks by hand, search, filter by status or priority, and open a task to see everything recorded about it. The board is the same data the agents see through the noise tasks command.
