# Making it mine

## Terminal and theme
advance_on: continue

The global menu sets the terminal font size and the color scheme, including your own colors. Auto-color projects gives each project its own tint in the side panel.

## Keyboard
advance_on: continue

Tab moves through the buttons and menus. The shortcuts for the side panel, the info bar, rename and yolo mode are printed next to each menu item. Inside the terminal, the agent's own shortcuts apply.
